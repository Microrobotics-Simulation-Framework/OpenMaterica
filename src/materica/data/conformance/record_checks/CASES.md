# Record-check cases: what each case file tests

One row per file in `cases/`, grouped by case id; each heading quotes the case's row in the
specification, which holds where the two differ. **Decided by** is the item of
`docs/specification/page_text.md` or `provenance.md` that decides the answer (`page_text.md` 2 where
section 2 flags the place), or `operation` for a `quote_sha256` operation. **Expected** is read from the
case file: the findings (`finds`) and the facts listed without failing (`lists`), each with the input and
the JSON pointer it is at, then the rules the case compares; or a `quote_sha256` operation's status and
hash, shortened here, never in the case files. See `README.md` beside this file for the fixtures and what
the cases cannot show.
